TNT SUBSTITUTION LIMITS (paper interpretation supplied by root)
Paper TNT T=0 through stance, a rising swing coordinate including pre-swing, estimator uses its own thigh-based state machine. Therefore it is not a full-cycle phase and not a direct replacement for physical HS/TO or stance elapsed/contact/force/stance fraction. Do not feed estimated thigh-transition pulses into legacy HS/TO slots and pretend equivalence.
TNT alone is many-to-one in stance: T=0 does not tell actor early/late stance or when to produce ankle push-off. A knee-centric swing estimator may help knee swing and ankle swing clearance, but full active ankle control requires added stance kinematic state/memory, especially pre-swing/push-off. A continuous full-stride phase model is a separate extension, not the cited TNT algorithm.
For a new kinematic-only schema preserve q_knee/ankle, qdot, SEA states, controller/governor states; add absolute thigh theta and angular rate; TNT scalar T, TNT derivative if robust, estimator state and validity, available completed-cycle durations, and sufficient estimator/filter memory (v_prev, theta_bm, T_bm, previous phase, extremum/branch/timer values actually used). Review whether expose all memory or use a recurrent actor. State exact schema after implementing audited estimator; no arbitrary promise actor35 stays35.
TNT is swing-local, so sin(2pi T),cos(2pi T) alone alias start and end of swing. Prefer scalar T plus explicit estimator mode/validity, or full-cycle sin/cos only after defining whole-stride phase.
Remove left force/contact from actor and right GRF-derived suffix6 from critic; delete/replace old HS/TO/FSM-derived observations rather than rename. TNT dynamics-based transitions have their own names and meanings. Do not preserve stale hidden GRF accesses in critic/reward/curriculum/reset/normalization. Existing dimensions/names/order/normalizers and checkpoint assumptions need versioning. Existing checkpoint requires distillation/retraining or explicit adapted student; same array width does not grant semantic compatibility.

BOOTSTRAP AND CAUSALITY
Current environment resets q/qdot from IK at requested episode time (simulation_runner.py335–347); three repeated start offsets at resolved config42–45. Binary baseline is sampled at t0 and may initialise an uncredited partial stance, not fake HS (prosthetic_phase_fsm.py243–279). TNT needs its own reset policy: unknown state/validity, causal warmup/history, calibration retained only when physically available; no loading completed future cycle to initialise extrema. Standing start and arbitrary mid-stride cold start differ.
Biological motion is not kinematically clamped: it is dynamically simulated muscle/reserve tracking of prescribed IK. ProstheticSegmentKinematics delegates biological references to base IK (osim_trj_cmc_like.py453–458), runner outer-loop call at simulation_runner.py864–870, biological PD reads actual q/qdot (outer_loop.py97–104). Thigh measured from actual state is a causal sensor, but in this testbed it is strongly driven by prescribed biological tracking. Success does not demonstrate autonomous locomotion or human response/adaptation. Validate sensor/estimator robustness at distinct starts and AB06/AB07/AB08, speed changes, pauses, mounting errors, and thigh/foot discordance.
